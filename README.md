 sosst-android-webview-wrapper
A lightweight Android WebView app for SOSST (sosst.com), providing fast access to the official website with a native app experience.
This is a lightweight Android application that wraps the official website https://sosst.com into a native WebView app.

 🚀 Features
- Fast access to SOSST website
- Lightweight and simple
- No login required
- Works like a native app
- Minimal permissions

 📱 What is this?
This app is not a standalone service. It is a WebView wrapper for the official SOSST platform, designed to provide a smoother mobile experience.
